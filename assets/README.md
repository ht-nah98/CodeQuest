# assets/ — Ảnh & âm thanh gốc

Nguồn trước khi xử lý. Kết quả đã xử lý nằm ở `apps/web/public/`.

| Thư mục | Nội dung |
|---|---|
| `raw/` | File gốc **không sửa** (vd `panda-sheet.png`: sprite gấu trúc 4×4 do HLV cung cấp) |
| `sprites/<nhân vật>/` | Khung đã làm sạch (nền trong suốt, căn đáy) |

**Đọc trước:** `docs/design/art-direction.md`, `docs/playbooks/add-asset.md`. Mọi asset bên thứ ba ghi vào `CREDITS.md`.
